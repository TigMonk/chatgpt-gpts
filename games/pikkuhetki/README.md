# Pikkuhetki

Mobiiliin tehty minipelikokoelma lyhyisiin taukoihin: 30 omaa peliä, onnenpyörä, raaputusarvat, päiväputki, päivän tehtävät, aarrearkku ja kumppanikupongit bonuksena.

Avaa `index.html` selaimessa. Edistyminen tallentuu selaimen localStorageen.

- **Pelit:** 6 auki heti, loput aukeavat tähdillä (tai 250 kolikolla). Jokaisessa 1–3 tähteä.
- **Koukut:** päivän peli (2× kolikot), päiväputki 7 päivän palkintokierrolla, 3 päivittäistä tehtävää, tasot ja XP, arkku joka 10. tähdellä, ilmainen pyöräytys joka 4. pelin jälkeen.
- **Kupongit:** pyörästä, arvoista, arkuista ja kaikkien päivän tehtävien bonuksena. Kumppanit ovat esimerkkejä; oikeat kumppanit vaihdetaan `PARTNERS`-listaan.
- **Reilu peli:** ei oikean rahan ostoja, pyörän todennäköisyydet näytetään (1/8 per lohko), taukomuistutus 20 minuutin jälkeen.
