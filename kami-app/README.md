# KAMI – Mentoripakka (selainsovellus, MVP)

Swipe-mentoripeli kahdella polulla:

- **🏯 Viisaus**: kamit, zen ja buddhalaisuus, eläimet, puut ja klassikot (Marcus Aurelius, Seneca, Saarnaaja, Koraani 94:5–6, Popol Vuh, Freud). Klassikot ovat omina käännöksinä.
- **🥊 Tsemppi**: leffa-, tosi-tv-, urheilu- ja meemiarkkityypit omin sanoin (Underdog-nyrkkeilijä, Reality-diiva, Sisu-mummo…)

| Tiedosto | Sisältö |
|----------|---------|
| `index.html` | Sovellus yhtenä tiedostona. Avaa selaimessa, ei asennusta. |
| `esite.html` | Esite: polut, toiminta, kolme tuotenäkökulmaa, oikeudet ja tiekartta |
| `TEKIJANOIKEUDET.md` | Selvitys sitaattien tekijänoikeuksista ja sisältöpolitiikka |

**Ohjaus:** 👉 osuu (palapelin pala) · 👈 ohi · ⬆️ syvemmälle (kortti kääntyy) · ⬇️ teko nyt. Toimii myös nuolinäppäimillä ja hiirellä vetämällä.

Tila (XP, putki, palat, periaatteet) tallentuu selaimen localStorageen.
